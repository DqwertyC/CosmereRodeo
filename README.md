# Owlbear Rodeo Dice + Cosmere RPG

3D dice extension, modified for the Cosmere RPG.
This project is a modified version of Owlbear Rodeos default [Dice Extension](https://github.com/owlbear-rodeo/dice).
Plot Dice assets were created by Dragonsteel and Brotherwise Games.
All other assets were created or sourced by Owlbear Rodeo.

## Installing

The extension can be installed by creating a custom plugin pointing to the linked Github Pages project.

## How it Works

This project uses [React](https://reactjs.org/) for UI, [Three.js](https://threejs.org/) for rendering and [Rapier](https://rapier.rs/) for physics.

The physics simulation is used to both generate the animation for the roll as well as the final roll values.
